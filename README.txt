REMPAH KAMPUNG KURING — WEBSITE PROTOTYPE

Cara melihat:
1. Ekstrak folder/ZIP ini.
2. Buka file index.html dengan Chrome, Edge, atau Firefox.
3. Koneksi internet diperlukan untuk memuat gambar ilustrasi dari Unsplash.

Cara mengubah:
- Buka index.html menggunakan VS Code atau editor teks.
- Konten, warna, layout, data informasi bahan, dan interaksi berada dalam file ini.
- Gambar produk saat ini hanya ilustrasi sementara, bukan foto produk asli.
- Kanal WhatsApp, Instagram, email, dan marketplace belum dihubungkan karena datanya belum tersedia.
- Informasi manfaat herbal masih berupa pengenalan umum dan harus ditinjau dengan referensi ilmiah/ketentuan yang berlaku sebelum website dipublikasikan untuk umum.

Publikasi GitHub Pages:
1. Buat repository baru di GitHub.
2. Unggah index.html (dan README bila diperlukan) ke root repository.
3. Buka Settings > Pages.
4. Pilih Deploy from a branch, pilih branch main dan folder /(root), lalu Save.
5. Tunggu proses publikasi, lalu gunakan URL GitHub Pages yang ditampilkan.
